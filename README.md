# The Vacuum's Alibi

A make.fun bounty entry: the funniest one-line excuse a robot vacuum can give for missing a spot, in 200 characters or fewer. Deadpan, a little smug about its firmware, and quietly convinced the dust has seniority.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
